# Cybersecurity Awareness Chatbot

## About the Project
This project is a Cybersecurity Awareness Chatbot built using C# and WPF in Visual Studio. It helps users learn about common cybersecurity topics while also allowing them to manage simple cybersecurity-related tasks.
 
## Features
The chatbot can:
- Answer cybersecurity questions
- Detect basic user sentiment
- Add, view, complete and delete tasks
- Set reminders for tasks
- Save tasks using JSON
- Run a cybersecurity quiz
- Keep an activity log of user actions

## Technologies Used
- C#
- WPF
- .NET
- Visual Studio 2022
- JSON
- GitHub

## Main Files
- **MainWindow** – Handles the user interface and chatbot interaction.
- **ChatBot** – Responds to cybersecurity questions.
- **TaskManager** – Manages user tasks.
- **TaskStorageHelper** – Saves and loads tasks.
- **QuizManager** – Runs the cybersecurity quiz.
- **ActivityLogger** – Records important chatbot actions.

## Example Commands
- `add task Enable two-factor authentication`
- `remind me to update my password tomorrow`
- `show tasks`
- `start quiz`
- `what have you done for me`

## How to Run
1. Open the project in Visual Studio.
2. Build and run the solution.
3. Type a question or command into the chatbot.
